The pad broke because he reused it. You broke it because you are not him. This chamber honors the first person to understand that a machine could be told to compute anything at all — including the sequence below. Her Note G, 1843, contains the first published program. It computed Bernoulli numbers. So will you.

TASK ORDER 97-11-03 / ANALYTICAL ENGINE
SEQUENCEBernoulli numbers Bn, with B2 = 1/6, B4 = −1/30 (the even-index convention; odd terms beyond B1 vanish).
CONDITIONFind the first even-indexed Bernoulli number whose numerator, in lowest terms, has absolute value greater than 100.
ANSWER FORMAT|numerator| written immediately followed by the denominator, no separators, no sign. Example: if the number were −1/30 you would enter 130. It is not −1/30.
METHODAny exact method. Floating point will lie to you. The engine of 1843 used fractions; so should yours.

The numerator you find is famous beyond this archive. Number theorists call it the first irregular prime. If your answer does not make a historian smile, your arithmetic is wrong.
